# Linker Changelog

[View Documentation](./index.md)

## 2026 / 08 / 03

> v1.0.2

#### 🌱 Added

- 🌸 Added the [points](./index.md#points-number-ipointdata) property for adding waypoint coordinates.

- 🌸 Added the [curve](./index.md#curve-ipointscurvedata) property for controlling curve curvature or customizing the smoothing method.

## 2026 / 07 / 14

> v1.0.1

#### 🪲 Fixed

- 🌸 Fixed an issue where connection elements could occasionally fail to render when dragging elements in the auto-connected direction after the connection element was nested within multiple layers.

#### 🌷 Feedback

@black

## 2026 / 06 / 02

> v1.0.0

#### 🌱 Added

- 🌸 After being validated in users' production environments with no significant issues, Linker is now officially released.

## 2026 / 03 / 30

> v1.0.0-beta.4

#### 🌱 Added

- 🌸 Added support for [creating connection elements by dragging](./plugin/official/linker/index.md#拖拽创建连线元素).

- 🌸 Added support for [connection elements with flow animations](./plugin/official/linker/index.md#带流动动画的连线元素).

- 🌸 Added support for [multiple modes](./plugin/official/linker/index.md#关键方法) when automatically creating connection points, allowing connections to snap to 4 directions, 8 directions, or any point.

#### 🪲 Fixed

- 🌸 Fixed an issue where automatically created connection points had incorrect directions when created through methods.

#### 🌷 Feedback

@CML
