# LeaferJS 功能大全：五年多开源积累，让 AI 图形开发更省 Token

> 2026-11-12 "让 AI 图形开发更简单、更省 Token"

##

**AI 能帮你写代码，但做图形应用，没必要每次都从 Canvas 底层开始。**

LeaferJS 把图形绘制、布局、交互、动画和编辑等常用能力做好了。借助 [LeaferJS Skills](https://www.leaferjs.com/ai/)，你可以让 AI 参考现成的 API 和插件，帮你开发无限画布、流程图、图形编辑器等应用，而不是反复实现底层功能。

即使没有编程基础，也可以尝试通过自然语言让 AI 协助创作；有开发经验的用户，则可以在已有能力上继续扩展。**目标不只是生成一张效果图，而是做出能交互、能编辑、能继续开发的应用。** 具体效果取决于所用 AI 工具和实际需求。

LeaferJS 从 **2021 年春天** 开始研发，至今五年多。我们一直希望把复杂的图形开发变得简单，让大家把时间花在自己的产品上，而不是重复造轮子。

**LeaferJS 基于 MIT 协议开源，免费可商用。** 大多数常见需求可以从开源引擎与生态插件开始；需要更高性能或专业编辑工具时，再按需选择 PxGrow。

[AI 上手](https://www.leaferjs.com/ai/) · [开发文档](https://www.leaferjs.com/ui/) · [GitHub](https://github.com/leaferjs/leafer-ui)

| 想做什么                               | LeaferJS 提供什么                                  |
| -------------------------------------- | -------------------------------------------------- |
| 无限画布、在线白板、流程图、AI视频分镜 | 画布缩放与平移、拖拽、连线、滚动条                 |
| 图形编辑器、设计工具                   | 选中与框选、移动、缩放、旋转、编组、自定义编辑工具 |
| 可视化应用、工业组态、数字孪生         | 图形、文本、图片、自动布局、事件、状态和样式       |
| 动画、小游戏、视频创作                 | 关键帧与路径动画、视频、GIF、精灵元素              |
| 跨端图形处理                           | Web、Web Worker、Node.js、微信小程序               |

## PxGrow：让开源走得更远

LeaferJS 会继续坚持 MIT 开源、免费可商用。为了让项目能够长期研发和维护，我们推出了 [PxGrow](https://www.pxgrow.com/)，提供可选的性能加速与专业图形编辑插件，并通过商业化支持 LeaferJS 的持续发展。

**开源引擎可以独立使用。** 如果项目对性能或专业编辑有更高要求，再按需选择 PxGrow。
