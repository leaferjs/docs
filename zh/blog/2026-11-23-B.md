# 让 AI 更懂 LeaferJS：我重新整理了官方 Skills

> 2026-11-20 · 让 AI 更懂 LeaferJS

##

最近，我在尝试用 AI + LeaferJS 测试做一些产品 Demo，发现了一些问题。

所以这段时间，我重新整理和优化了 LeaferJS Skills，希望让 AI 更容易找到并正确使用已有能力，也让更多人能够借助 AI 开始创作。

## 01 让 AI 更容易找到需要的能力

以前，我们已经为 AI 准备了大量官方文档、示例和源码。

但文档多，不代表 AI 就能用好。特别是面对复杂的图形应用，如何快速找到正确的 API 和插件，比单纯提供更多内容更重要。

这次主要做了几方面调整。

**1. 重新整理文档内容和目录索引**

将开发指南、API 参考、插件文档重新整理了一下，并分别建立了文档索引，保留原有的多级目录结构。

AI 可以先通过本地关键词搜索或文档索引定位，再按需读取相关文档和示例，无需一次性加载整个知识库，减少 Token 消耗。

**2. 优先使用官方示例和插件**

整理了现有插件的用途和使用方式，明确告诉 AI：开发之前，先看看 LeaferJS 有没有现成的能力。

比如画布缩放、图形编辑、文本编辑、连线、自动布局、动画和图片导出，都有对应的插件或 API 可以使用。

能用现成的，就不必从底层重新实现。

**3. 让 AI 不只会写代码，还要把应用做出来**

优化了 Skill 的开发指引，让 AI 根据需求选择合适的能力，参考官方示例完成开发，并尽可能运行、检查和修复问题。

对于已有项目，也可以结合项目代码、API 文档和源码进行修改，而不是重新生成一套不相关的实现。

这些调整没有增加什么神奇的新能力，只是让 AI 更容易用好 LeaferJS 已经具备的能力。

**代码不一定要写得更多，关键是少走弯路。**

## 02 接下来还会继续优化

这次调整只是一个开始。

后面我还会根据实际使用情况继续完善官方示例、文档索引和插件知识，让 AI 能够更准确地理解和使用 LeaferJS。

还未安装过的用户，可以通过以下命令安装：

```sh
npx skills add leaferjs/leafer-ai
```

对于已经安装过的用户，可以通过下面的命令更新：

```bash
npx skills update leaferjs
```
