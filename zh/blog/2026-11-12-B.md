# LeaferJS 的不同之处：与 Fabric.js、Konva.js、PixiJS 的功能对比

> 2026-11-12 "我们的的不同之处"

##

**专注图形交互、编辑场景**

LeaferJS 从 2021 年开始研发，一直在思考怎样让图形交互和编辑开发更简单。

画出一个矩形不难，难的是让大量元素能够正常布局、响应事件、保持编辑状态，还能方便地组合成真正的产品。为此，我们在图形渲染之外，持续完善了坐标、包围盒、布局、交互、动画和编辑器等能力。

这篇文章把 LeaferJS 与 Fabric.js、Konva.js、PixiJS 放在一起，看看各自提供了哪些现成能力。**目的不是比较谁更强，而是帮助开发者了解 LeaferJS 的设计侧重点，减少技术选型时的信息成本。**

## 四个框架，各有侧重

| 框架                                  | 主要关注的方向                                                       |
| ------------------------------------- | -------------------------------------------------------------------- |
| [LeaferJS](https://www.leaferjs.com/) | Canvas 图形绘制、交互、布局和编辑，提供面向不同应用形态的 API 与插件 |
| [Fabric.js](https://fabricjs.com/)    | 面向对象的 Canvas 绘图、对象操作与编辑、导入导出                     |
| [Konva.js](https://konvajs.org/)      | Canvas 场景树、事件、拖拽、分层渲染和交互图形                        |
| [PixiJS](https://pixijs.com/)         | 基于 WebGL / WebGPU 的 2D GPU 渲染、动画和丰富的视觉效果             |

这些方向并不互斥。多数图形应用都能通过不同框架实现，区别更多在于：**需要自己补齐多少基础能力，以及是否符合现有架构。**

## LeaferJS 值得关注的一些细节

以下是我们在图形交互、编辑开发中重点完善的部分。它们未必是 LeaferJS 独有的技术，但在实际项目中很常用：

| 能力                                                                            | 解决的问题                                               |
| ------------------------------------------------------------------------------- | -------------------------------------------------------- |
| [方位与边缘布局](https://www.leaferjs.com/ui/reference/UI/position.html)        | 让元素按父级或目标元素的方位、边缘定位，不必反复手算坐标 |
| [坐标与包围盒体系](https://www.leaferjs.com/ui/guide/advanced/bounds.html)      | 在多层嵌套、缩放和旋转后，仍能方便地计算位置和范围       |
| [包围盒变化事件](https://www.leaferjs.com/ui/reference/event/basic/Bounds.html) | 元素尺寸或包围盒发生变化时，可直接监听并响应             |
| [事件穿透](https://www.leaferjs.com/ui/reference/event/ui/UIEvent.html)         | 处理元素重叠时，可以找到被上层遮挡的目标元素             |
| [交互状态](https://www.leaferjs.com/ui/guide/plugin/state.html)                 | 为 hover、press、selected 等状态统一配置样式和过渡       |
| [图形编辑器](https://www.leaferjs.com/ui/plugin/in/editor/)                     | 提供多选、框选、编组、进组编辑和可扩展的编辑工具         |

## 最后

Fabric.js、Konva.js、PixiJS 都有各自成熟的能力和使用场景。LeaferJS 选择在图形交互、布局和编辑上继续深入，并不是要替代所有框架，而是希望把这些经常用到的基础能力做好，让开发者少一些重复实现。

选型时，除了看功能是否支持，也建议结合渲染方案、插件维护、运行环境和项目实际需求进行验证。对于尚未确认的条目，我们会继续补充和修正。
